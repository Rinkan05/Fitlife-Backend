Arquitectura AWS – Evaluación N.º 4
Autenticación Stateless (JWT)

A diferencia de sesiones clásicas, el token JWT viaja en cada cabecera HTTP de forma stateless. El backend puede escalar horizontalmente en múltiples EC2 detrás del API Gateway sin compartir memoria de sesiones.

Rate Limiting – API Gateway

El API Gateway tiene configurado Burst=5, Rate=2 req/s. Al superar el límite, el cliente recibe 429 Too Many Requests, protegiendo el backend de ataques DDoS.

Backup Automático (Lambda)

Una función Lambda con EventBridge crea snapshots de RDS cada 7 horas. CloudWatch + SNS envía alertas de CPU al email del administrador.
